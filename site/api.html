完整 API

uitest-sdk 0.11.0 · hypium 6.1.0.210 · 118 个方法

DevEco Testing 的 hypium 驱动在设备上公开 118 个方法（OHOSDriver 106 个 + 兼容层 12 个）。dev.hypium 把它们逐个映射成 TypeScript 的同名 camelCase 方法，参数与返回值按设备实际行为定，不是照着文档猜的：每一条都在真机（BRA-AL00 / uitest 7.0.0.1）上跑过，状态标在表里。

import { Device, UnsupportedError } from "uitest-sdk";
import { Gesture, On } from "uitest-sdk/drivers";

const dev = await Device.connect();
try {
  await dev.hypium.click(On.text("设置"));
  await dev.hypium.waitForComponent(On.text("WLAN"), { timeoutMs: 3000 });
} finally {
  await dev.dispose();
}

与 hypium 的差异

  • sn() 返回设备序列号的 8 位哈希（如 6c585f5b），原始序列号不会出现在任何返回值、trace 或报告里。
  • Toast 与 UI 事件五个方法抛 UnsupportedError：设备侧的 UIEventObserver 会从 start 返回，但对 getRecentUiEvent 永不回复（实测 30 秒超时）。
  • findImage 只有模板匹配（mode: "template"，JPEG 模板）；sift 需要主机侧 OpenCV，传了会明确报错。
  • setDisplayRotation 只接受 0/1/2/3；设备参数校验器拒绝字符串。
  • ScreenLock.isLocked() 读真实锁屏状态，而不是固定返回 false。
  • pushFile 会把本地路径转成绝对路径再发：实测相对路径会被 hdc 当成目录树，在设备上建出一个同名文件夹。
