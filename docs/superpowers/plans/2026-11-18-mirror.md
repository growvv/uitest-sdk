# uitest-mirror 0.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `uitest-mirror@0.1.0`, a HarmonyOS scrcpy, as the fourth package in this repo — with core 0.11.0, console 0.1.2 and phone 0.10.2 released in the same batch and every product separately accepted with screenshot reports on the site.

**Architecture:** core grows four capabilities (a promoted app-window helper, a Recents key, `keepAwake`, and `maxSize` resolved per transport). The console deletes its private window module and imports core's. `uitest-mirror` is a thin product: its own scrcpy-style argument parser, `connect()` with a lease, core's viewer with inspect/capture/privacy off, and core's player page unchanged.

**Tech Stack:** TypeScript (ESM, NodeNext), npm workspaces, vitest, tsc, Playwright via `scripts/screenshot.mjs`, `hdc` for device work.

**Spec:** `docs/superpowers/specs/2026-11-18-mirror-design.md`

## Global Constraints

- **Dependency edges:** only `uitest-phone | uitest-console | uitest-mirror → uitest-sdk`. No product imports another. `scripts/check-layers.mjs` enforces it.
- **Version ranges:** every product declares `"uitest-sdk": "~0.11.0"`. Workspace versions must equal the range, or npm resolves from the registry.
- **Never write a real device serial** into a tracked file, doc, commit or site page. Use the 8-char tags from `tagOf()` — `7544d645` and `6c585f5b`.
- **Never write a token value** into a repo file, doc or commit. npm publishing uses a temporary npmrc outside the repo, deleted afterwards.
- **Do not blindly kill daemons.** Only processes this run started, or when no session is active.
- **No silent transport fallback.** `--transport ws` without the 7.0 extension is an error, never a downgrade to grpc.
- **`unset HDC_SERVER_PORT`** before any device work.
- **Every failure is a `UitestError` subclass with a stable `code`** so `exitCodeForError` can classify it.
- **Test evidence tree:** every acceptance runner excludes `docs/acceptance` via `gitHead({ exclude: [relative(ROOT, EVIDENCE)] })`.
- **TDD:** every production change is preceded by a test watched failing.

## Review Focus

1. **A person passes `--max-size` larger than the device's native width.** They expect no error and a full-size picture. `resolveCastScale` must return 1, not 0 or a negative.
2. **A person passes `--max-size` so small the extension cannot honour it** (needs divisor > 5). They expect a clear refusal naming what is achievable, not a silently-clamped wrong size.
3. **The device is asleep or locked when `uitest-mirror` starts.** They expect a message they can act on; the page must not sit on "starting…" forever with no explanation.
4. **Two mirrors are started, or an agent holds the device.** They expect the second one to exit with the holder named, not to steal the device or leave a half-open forward.
5. **`--record` is given but nobody clicks the page's record button.** The person expects a file when the window closes, because they named the file on the command line.

import { describe, expect, it } from "vitest";
import { resolveCastScale } from "../../src/cast/scale.js";

describe("resolveCastScale", () => {
  // The extension takes an integer divisor, 1..5.
  it.each([
    [2720, 1024, 3],
    [2720, 2720, 1],
    [2720, 5000, 1],
    [2720, 900, 4],
  ])("grpc: longest %i at max %i -> divisor %i", (longest, maxSize, want) => {
    expect(resolveCastScale("grpc", longest, { maxSize })).toBe(want);
  });

  // MJPEG's scale is a fraction, so the same maxSize means something else.
  it("mjpeg: a fraction, not a divisor", () => {
    expect(resolveCastScale("mjpeg", 2720, { maxSize: 1360 })).toBe(0.5);
    expect(resolveCastScale("mjpeg", 2720, { maxSize: 5000 })).toBe(1);
  });

  // A person asking for a size the extension cannot reach gets told, not a
  // silently clamped picture that is twice what they asked for.
  it("refuses a size below what a 5x shrink can reach", () => {
    expect(() => resolveCastScale("grpc", 2720, { maxSize: 300 })).toThrow(/544/);
  });

  it("refuses scale and maxSize together", () => {
    expect(() => resolveCastScale("grpc", 2720, { scale: 2, maxSize: 1024 })).toThrow(/EBADARG|both/);
  });

  it("passes an explicit scale through untouched", () => {
    expect(resolveCastScale("grpc", 2720, { scale: 2 })).toBe(2);
    expect(resolveCastScale("mjpeg", 2720, { scale: 0.25 })).toBe(0.25);
  });
});
